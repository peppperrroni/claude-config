# State

Where the work stopped and what is next. One entry per session, newest first.

**Belongs here:** what was finished, what was left half-done and why, what the next step
is, which branch the work is on.
**Does not belong here:** what the code does, how it is structured, a changelog of
commits. `git log` already has those, and a second copy of them goes stale silently.

**Branch.** <branch name, and whether it is green>
