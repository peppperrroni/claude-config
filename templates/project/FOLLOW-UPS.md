# Follow-ups

Known defects and work deliberately deferred.

**Belongs here:** a defect that is known and not yet fixed, with the symptom by which it
is recognised; work that was consciously postponed, with what triggers doing it.
**Does not belong here:** a wishlist. An item nobody intends to act on is noise, and
noise makes the real entries invisible. Delete it instead of demoting it.

An item leaves this file when it is fixed — in the same commit as the fix, with the test
that proves it.
