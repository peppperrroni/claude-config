# Decisions

What was decided, and why it went that way. Append only; never rewrite an entry, because
a decision that was later reversed is still a decision that was made.

**Belongs here:** the choice, the alternatives that were rejected, and the reason —
especially a reason that is no longer visible in the code. A constraint that came from
outside the repository (a platform limit, a deadline, a person) belongs here too.
**Does not belong here:** what the chosen approach does. The code says that. This file
exists for the part the code cannot say: what it was weighed against.
